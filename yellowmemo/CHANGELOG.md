날짜가 확인되는 작업만 날짜를 붙였습니다. 초기의 세부 수정 순서는 대화 기록으로 정리했으며, 존재하지 않는 Git 커밋이나 릴리스 번호를 만들지 않았습니다.

## v1.0.0 배포 준비 — 2026-11-01

- 마지막 소스를 기준으로 공개 저장소 구조를 구성했습니다.
- 개발 과정, 사용자 안내, 검증 보고서, GitHub 업로드 안내를 작성했습니다.
- 빌드·테스트·배포 ZIP 생성 스크립트와 개인정보 제외 규칙을 추가했습니다.
- 앱 기능 코드는 기존 최종본을 유지했습니다.
- 공개용 ZIP에는 실행 파일과 사용 안내만 포함합니다.
- GitHub에 실제 업로드하거나 Release를 게시한 단계는 아닙니다.

## 저장 위치·입력 처리 수정 — 2026-10-17

- 실행 파일 옆 저장에서 Windows 사용자 계정의 LocalAppData 고정 저장으로 전환했습니다.
- 기존 메모를 최초 실행 시 가져오고 기존 고정 저장 파일은 덮어쓰지 않게 했습니다.
- TextChanged에서 매번 실행하던 전체 문서 줄 간격 적용·RTF 변환·목록 갱신을 지연 처리로 바꿨습니다.
- 한글 조합 중 캡처와 자동 저장을 미룹니다.
- 입력 정지 후 약 900ms에 문서를 캡처하고 파일 저장을 백그라운드에서 수행합니다.
- 저장 중 추가 입력과 종료 시 마지막 입력 보존 검사를 추가했습니다.
- 실제 한글 IME 입력의 완전한 해결 여부는 직접 검증하지 못했습니다.

## 초기 개발과 기능 정리 — 2026-10-02까지 확인된 기록

1. 노란 배경·얇은 가로선·줄바꿈·메모 분류를 갖춘 앱을 만들기 시작했습니다.
2. 일반 메모 창에서 바탕화면에 계속 두는 위젯 형태로 요구사항을 구체화했습니다.
3. 줄 간격과 기본 글자 크기를 줄이고 크기·굵기 선택을 추가했습니다.
4. 상단에서 메모를 선택하도록 개선하고 다른 창 뒤로 갈 수 있게 했습니다.
5. 사용자의 요청으로 폴더 분류 UI를 제거했습니다. 기존 데이터 필드는 호환성을 위해 남겼습니다.
6. 이전 실행 파일들을 정리하고 최종 실행 파일을 유지했습니다. 필요한 메모 원본과 백업은 보존했습니다.
7. 항상 위 UI와 동작을 제거했습니다.
8. 수정 시 위치가 바뀌지 않는 작성 순, 본문 글자 수를 기준으로 하는 크기 순을 추가했습니다.
9. 제목·본문 검색, 오프라인 사용, 개인 메모와 실행 파일의 분리를 확인했습니다.
10. 개인 메모가 포함되지 않은 공유용 ZIP을 만들었습니다.
