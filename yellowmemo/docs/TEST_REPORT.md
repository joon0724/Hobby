# 검증 보고서

검사일: **2026-11-01**  
대상: **YellowMemo v1.0.0 공개용 패키지**  
앱 기능 소스: 2026-10-17 최종 수정본을 그대로 복사한 src/YellowMemo.cs

## 1. 이번에 실제 수행한 검사

PowerShell 7.6.5에서 패키징을 실행한 뒤, 안내한 사용 환경인 Windows PowerShell 5.1에서도 전체 패키징을 실행했습니다. 두 실행에서 빌드와 모든 자동 검사가 성공했습니다.

컴파일러 파일 버전: 4.8.9221.0. Windows에 설치된 .NET Framework C# 컴파일러와 WPF 참조를 사용했습니다.

```powershell
.\scripts\package.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

| 항목 | 결과 | 범위 |
|---|---|---|
| C# 빌드 | PASS | 실행 파일 생성 |
| 저장 검사 | PASS | 한글·여러 줄·이모지 왕복, 직전 백업, 잘못된 데이터 거부 |
| 저장 위치 이전 | PASS | 원본 바이트 보존, 새 EXE 경로, 최신 고정 저장 우선, 백업, 원본 잠금 |
| 정렬·검색 | PASS | 생성 순서 유지, 크기와 동률, 설정 보존, 제목·본문 검색 |
| 서식·레이아웃 | PASS | 부분 서식, 실행 취소, 빈 문서 입력 서식, 줄바꿈·스크롤 |
| 위젯 | PASS | 접기·펼치기, 종료 대신 접기, 위치 복구, 항상 위 해제 |
| 지연 입력 처리 | PASS | 매 입력마다 RTF 변환하지 않음, 조합 중 캡처·저장 지연 |
| 비동기 저장과 종료 | PASS | 이전 스냅샷 저장 중 새 입력을 추가한 뒤 최신 내용 저장 |
| 공개 ZIP | PASS | 허용한 2개 파일만 포함, ZIP 안의 EXE와 빌드 EXE 해시 일치 |
| 소스 보존 | PASS | 제공된 최종 소스와 공개용 소스의 SHA-256 일치 |

입력 회귀 검사는 100,000글자 문서에 프로그램적으로 100번 추가 입력하는 루프입니다. 최종 Windows PowerShell 실행에서는 이 루프가 **59ms**였고, 루프 안에서 RTF 전체 변환 횟수는 증가하지 않았습니다. 이 수치는 특정 실행의 관측값이며 전체 입력 지연이나 실제 IME 성능 보장값이 아닙니다. 앞선 PowerShell 7 실행에서는 65ms였습니다.

## 2. 개인 정보와 패키지 범위

- 개인 메모 파일이나 AppData의 사용자 저장 파일을 테스트에 사용하지 않았습니다.
- 검사 모드는 새 작업 폴더와 합성 메모를 사용합니다.
- assets의 두 화면은 기본 안내 메모를 사용한 검사 결과이며 실제 사용자 메모가 아닙니다.
- 배포 ZIP의 내용은 YellowMemoWidget3.exe와 USER_GUIDE.md뿐입니다.
- 파일 단위 허용 목록으로 공개 폴더를 구성하고 artifacts·data·백업을 제외합니다.
- .gitignore에 개인 데이터·백업·작업 출력 제외 규칙을 넣었습니다.

## 4. 자동 검사로 확인하지 못한 것

- 실제 물리 키보드와 Microsoft 한글 IME의 조합 재현 및 완전 해결 여부
- 모든 Windows 버전, DPI 배율, 다중 모니터 구성
- 다른 PC·새 Windows 계정에서의 실제 설치·이전 경험
- 강제 전원 차단 시 저장되지 않은 입력의 보존
- 수백만 글자, 매우 많은 메모 등 모든 대용량 사용 상황
- GitHub 원격 push, Release 게시, 원격 CI
- 디지털 코드 서명과 설치 프로그램

따라서 이 패키지를 “모든 한글 입력 버그가 해결된 버전”이나 “모든 환경에서 검증된 버전”으로 소개하지 않습니다.

## 5. 수동 한글 입력 확인 절차

개인 메모를 쓰지 않는 검사용 경로를 지정해 다음 명령으로 별도 창을 열 수 있습니다. 이 모드는 지정한 폴더에 검사 데이터를 만들며 AppData의 개인 메모를 열지 않습니다.

```powershell
New-Item -ItemType Directory -Force .\artifacts\manual-ime
.\artifacts\build\YellowMemoWidget3.exe --input-test "$PWD\artifacts\manual-ime"
```

1. 새 메모를 만들고 Microsoft 한글 IME로 전환합니다.
2. 제목과 본문 각각에 “를”, “읽고”, “값을”, “앉았다”를 입력합니다.
3. 초성·중성 입력 후 1초 이상 멈췄다가 받침을 입력합니다.
4. 빠른 연속 입력, Enter, Backspace, Ctrl+Z를 확인합니다.
5. 크기·굵기를 바꾼 뒤 같은 문장을 입력합니다.
6. Ctrl+S 후 앱 종료하고 같은 검사 경로로 다시 열어 결과를 비교합니다.

이 절차는 다음 검증을 위한 안내이며 이번에 사람이 직접 통과한 결과로 기록하지 않았습니다.
