# 한 장 · YellowMemo v1.0.0

Windows 바탕화면에 두고 사용하는 노란 줄노트 메모 위젯의 첫 공개용 패키지입니다.

## 포함된 기능

- 작은 메모 창, 목록 창, 접기·펼치기, 알림 영역 아이콘
- 기본 10pt 글자, 22px 줄 간격, 글자 크기·굵기 선택
- 메모 선택·검색·작성 순/크기 순 정렬
- 오프라인 자동 저장과 직전 저장본 백업
- 같은 PC·같은 Windows 계정에서 앱 폴더 이동 후 메모 유지
- 한글 조합 중 문서 처리·저장을 지연하도록 개선

## 사용

Windows에서 ZIP을 압축 해제하고 YellowMemoWidget3.exe를 실행하세요. 완전 종료는 ⋯ → 앱 종료입니다.

기존 버전은 종료한 뒤 업데이트하세요. 최초 이전은 기존 data 폴더가 EXE 옆에 있는 위치에서 실행하면 됩니다. 이후 메모는 %LOCALAPPDATA%\YellowMemo\data에 저장됩니다.

## 검증 및 제한

저장·이전·정렬·검색·서식·위젯·입력 지연 처리의 자동 검사를 제공합니다. 실제 한글 IME에서 받침 입력 문제가 완전히 해결됐는지는 사용자 환경 검증이 필요합니다.

배포 파일은 코드 서명되지 않았으며 설치 프로그램·자동 업데이트·클라우드 동기화는 없습니다. 개인 메모는 포함하지 않았습니다.
